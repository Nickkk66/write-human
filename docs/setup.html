Set up Write Human

It runs on your own computer, so your docs stay with you. Do this once, then sign in with ChatGPT.

You need Node.js 22.12 or newer, Git, and a ChatGPT Go, Plus, or Pro plan. Run these in a terminal (on Windows, PowerShell).

  1. 1
    Download it
    git clone https://github.com/Nickkk66/write-human.git
cd write-human
  2. 2
    Set it up
    npm run setup

    This installs everything it needs, including OpenAI's official sign-in kit.

  3. 3
    Start it
    npm start

    Leave that window open while you use Write Human.

  4. 4
    Sign in

    Once it's running, this opens Write Human on your computer and signs you in with your ChatGPT plan.

    Continue with ChatGPT

    Nothing loads? Check that the npm start window is still open.
